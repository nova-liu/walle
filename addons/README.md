这里放**不属于原作者 chillibasket 原始 75 个 STL** 的补充零件。它们和主打印集分开管理：

- 主打印集：`to-print/`（65 个文件 / 316 件），来自原作者
- 本目录：第三方 remix，按需单独送打，**不计入 316 件**

## interior-electronics-box 状态

已下载 3 个 STL，评估记录见 [interior-electronics-box/README.md](interior-electronics-box/README.md)。

一句话结论：**有用的部分是它给出的 129 × 116 mm 机身底板尺寸和固定孔位**，但盒子本身只有 0.44 L 可用，装不下全部器件。

## 为什么要单独放

原版机身里**没有任何给电子件的固定孔**。作者当初是把 Pi 和 Uno 自己塞进去的。我们要装 5 块板子，所以需要一个安装盒。

但注意：christinloehner 这个盒子是按**他自己的电子件**设计的，尺寸未必匹配我们的组合（Pi 4 + 双降压 + 3S 电池）。量过尺寸之后再决定用它、改它、还是自己画。
